# batalla-pokemon-martinhorjales

### Aplicación de batallas pokemon de martin horjales UDAW2 

Repo: https://github.com/martinhorjales/batalla-pokemon-martinhorjales.git

### Creacion entorno virtual: 
```
 -m venv venv
```
### Instalación de flask con los requerimientos:
```
.\venv\Scripts\pip install -r requirements.txt
 ```

 ### Estructura:
 ```
 mi_proyecto/
├─ requirements.txt
├─ venv/
└─ app/
   └─ main.py
```
### A medida que el proyecto avance, dentro de app/ irán apareciendo:

*  templates/ — las plantillas HTML de Jinja (aparece al final de esta unidad).

* static/ — CSS, JavaScript e imágenes (UD3).

* routes/ — las rutas repartidas en varios ficheros, en vez de todas en main.py (UD5).

* models.py o models/ — las clases que representan los datos (UD6).
